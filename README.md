# 3D-Part-Decomposition.github.io

Project page for prompt-driven multi-part SDF decomposition on a frozen TripoSG shape VAE.

- `index.html` — architecture + the overfitting experiment (13 assets, 1 prompt point per part)
- `assets/overfit/<sha>/{input,whole,ours,gt}.glb` — decimated meshes for the viewer
- `sam3d-gallery/` — the earlier 2D-segmentation gallery, kept rather than deleted
